# Atlas

Knowledge base (mini CMS) para practicar el slice fullstack del rol Java + Spring Boot + React.

**Guía de aprendizaje (tú implementas, el agente no genera el código):** [planning/atlas_java_spring.plan.md](planning/atlas_java_spring.plan.md)

Stack: Java 17, Spring Boot 3.x, PostgreSQL 16, React + TypeScript. Orden: DB → API → JWT → lectura → Publish + caché.

Carpetas: `backend/`, `frontend/` (vacías hasta que sigas la guía).
